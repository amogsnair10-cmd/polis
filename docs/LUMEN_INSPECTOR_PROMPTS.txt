INSPECTOR LUMEN: PROMPTS FOR GPT IMAGE GENERATION
Light Bulb app mascot (deadpan firefly detective). 10 character sheets x 6 poses = 60 poses, plus 3 bonus single images.
======================================================================

HOW TO USE
1. Start a NEW chat in ChatGPT with image generation. In your FIRST message attach the MASTER REFERENCE
   (the sunglasses version of Lumen) and paste the CHARACTER LOCK below. Say: 'Remember this character.
   I will send prompts one by one.'
2. Paste ONE sheet prompt at a time (each is complete). Ask for ONE image per message.
3. If Lumen drifts (head colour, hat, bulb, wings), re-attach the master reference and add:
   'Match the reference exactly. Do not redesign anything.'
4. If a sheet has the wrong number of poses or any text, reply: 'Redo with exactly 6 poses in a 3x2 grid and no text.'
   If the poses all look alike, reply: 'Redo. Every pose needs a different camera angle and body position, exactly as listed. Keep the character identical.'
5. Save each sheet as PNG and send it to Claude in the chat. Claude cuts out each pose, makes small
   transparent files and puts them in the app (quiz results, streaks, badges, empty screens, loading screen,
   widgets).
6. Tip: generate Sheet 1 first. If Lumen looks right there, keep going in that same chat.
