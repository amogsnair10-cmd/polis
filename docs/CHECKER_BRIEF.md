# Checker brief (cheap model, one per batch)

Run `node scripts/lint.js <DIR>` first. It catches format, length, tiny diagram text and repeated
questions for free, so do NOT check those by hand.

Your only job is facts. For the lesson files given:
1. Read each file once.
2. List every claim that could be wrong: dates, numbers, names, book titles, quotes, Articles, cases, and anything after 2022.
3. Web-search only the doubtful ones (≤3 per lesson). Do not re-check well-known textbook facts.
4. Check each quiz key is correct.

Do not edit files. Reply with a table only: lesson id | card/quiz no. | wrong text | correct text | source.
Skip "looks fine" items.
